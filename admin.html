Almost there: 3 quick steps on Vercel

  1. Add the database. Vercel → this project → Storage → Create Database → Upstash for Redis (the free plan is fine) → connect it to this project, all environments.
  2. Pick a password for this page. Vercel → this project → Settings → Environment Variables → add ADMIN_PASSWORD with the password you want.
  3. Redeploy. Vercel → Deployments → the ⋯ menu on the latest one → Redeploy. Then reload this page.

Optional: TRACK_TIMEZONE (e.g. America/Los_Angeles) sets which time zone "today" uses. The default is New York time.
